Дипломная работа по теме:
**Реализация ИИ-агента в задаче мониторинга портфеля в кредитных рисках**


В данной работе рассматривается:

1. Разработка скоринговой модели
2. Валидация и интерпретация на предмет корректности предсказаний
3. Реализация телеграм бота на базе GigaChatAPI (обработка естественного языка), Aiogram (асинхронная библиотека для подключения к Telegram API)  для сбора анкетной информации из заявки.
